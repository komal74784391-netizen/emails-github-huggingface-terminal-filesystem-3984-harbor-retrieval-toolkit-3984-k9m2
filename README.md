# harbor-retrieval-toolkit

Reference implementation for *Harbor: A Toolkit for Reproducible Retrieval
Baselines* (Journal of Open Source Software 2025).

Released under the MIT license. The toolkit and its baseline configurations are
included.

## Layout

- `src/harbor/` — baseline implementations
- `configs/` — baseline configurations
- `experiments/` — evaluation drivers
- `data/` — pointers to the public BEIR split
